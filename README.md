# はなうた帳 🎶

スマホで鼻歌をメモするための、小さなピアノロール。
コードを選んで、スケールの色を見ながらメロを置く。歌詞も一緒に残せる。

ふつうのDAWの「小さい版」ではなく、**できることを先に絞った別の道具**です。
ボタンは少なく、指で置けて、MIDIで持ち出せる。それだけ。

## できること

- キーとスケール（メジャー／マイナー）。スケール内の段に色、根音は濃い色
- コードの段：ダイアトニックコード＋その他（7 / M7 / m7 / sus4 / 7sus4 / dim / dim7 / m7♭5 / aug / add9 / m(add9)）、オンコード、1小節に2つ
- メロの段：タップで置く・長押しで消す・引いて動かす・右端で伸び縮み
- グリッド 1/16〜1/2、ルーラーのタップでループ範囲
- リズム：ふつう／シャッフル／ハーフタイムシャッフル
- メトロノーム、テンポ
- トラックの複製・追加・削除・改名
- 歌詞メモ（曲ごと・流しながら書ける・.txt で持ち出し）
- 曲の一覧（複数の曲を持てる・複製・名前変更）
- 自動保存（ブラウザの記憶）＋ 控えのコピー／復元
- MIDI書き出し（トラック単位・共有シートから Cubase などへ）

## 使い方

公開ページをスマホのブラウザで開いて、ホーム画面に追加すると、アプリのように使えます。
データは端末のブラウザの中にだけ保存されます。サーバーには何も送りません。

## 中身

- `hanauta.html` … 本体（1ファイル・依存なし）
- `docs/index.html` … 公開用に包んだもの（`py -X utf8 build_pages.py` で生成）
- `build_pages.py` … 包む配管
